Offline-First Architecture

Bekerja Optimal Tanpa Internet dengan SQLite

Aplikasi dirancang dengan pendekatan offline-first. Pada kondisi tanpa internet, aplikasi menggunakan SQLite sebagai database lokal sehingga seluruh fitur utama tetap dapat diakses. Sinkronisasi ke cloud otomatis berjalan saat online bagi pengguna Premium.

Tech Stack & Tools

  • Mobile Frontend Flutter & Dart
  • Backend Cloud Laravel REST API
  • Local Database SQLite
  • Push Notification Firebase Cloud Messaging (FCM)
